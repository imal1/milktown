# 最近文件存在 localStorage 里

最近文件列表持久化到 webview 的 `localStorage`，不落到磁盘，也不进 `.milktown/`。

理由：这是本应用最不重要的数据。丢了的后果是用户少一个跳转入口，重新走一次 `⇧⌘O` 就补回来了。为它引入一个存储层——无论是应用数据目录里的 JSON 还是 SQLite——都是在给一份可再生的便利数据配一套不可再生数据的基础设施。

## Consequences

- 换电脑、清空 webview 数据，最近文件列表消失。接受。
- 存储不可用（隐私模式、配额满、浏览器禁用）时读写都会抛，模块统一吞掉，返回空列表。写作不受影响。
- 列表长度封顶 12 条，重复打开同一路径只更新时间不新增条目，打开失败的路径被移除。
- 模块通过注入的键值端口工作（`KeyValuePort`），所以上面这些行为可以在 node 环境里测，不需要浏览器。
