# 三个双页视图共用一条真相源规矩

「双页视图」现在有三个：**原文对照**（⌥⌘/，排版与原文并排）、**磁盘对照**（⇧⌘/，磁盘上那份与当前这份并排）、**版本对照**（⇧⌘H，历史里的某一版与当前这份并排）。它们形态相同——并排两栏、接管整个窗口、只读、Esc 退出——所以关于真相源它们只需要一条规矩，而不是三条。

规矩是：**进任何一个双页视图之前，真相源先交回编辑器**。人在源码模式里按 ⌥⌘/，应用替他按一次 ⌘/ 再进；Esc 退出时永远回到写作视图，不回源码模式。

这是 ADR 0009 的延续。0009 只处理了 ⇧⌘H 一个入口（「⇧⌘H 在源码模式下先自动退回写作视图」），当时只有那一个双页视图。现在有三个，把那条特例升成通则。

## Considered Options

- **让双页视图叠在源码模式上** —— 从源码模式进、退回源码模式，看起来更「不打断」。但双页视图的差异本来就是源码级的（ADR 0006），底下那层是排版还是纯文本对显示毫无影响；换来的是四个模式两两组合的状态空间，以及「把版本装回编辑器」有两个可能的目的地。拒绝。
- **进双页视图时禁用源码模式的快捷键** —— 状态空间是干净了，但人得先自己按 ⌘/ 才能按 ⌥⌘/，凭什么？拒绝。
- **进入前自动交接** —— 采纳。四个视图（源码模式、原文对照、磁盘对照、版本对照）构成一个互斥组，菜单里带对钩，任何时刻至多一个打钩。

## 双页里的两栏是快照

两栏的内容都是**进入那一刻取的快照**，只读，退出即丢弃。不跟着磁盘变，不跟着编辑器变——双页视图里没有编辑器，编辑器在进入时已经交出了内容。

退出回到写作视图时，光标落回进入前所在的那一段：进入时记的是块位置，不是字符偏移量，因为对照的单位本来就是段（ADR 0014 同一个口径）。

## 磁盘对照的两种没得比

- **没有当前文件**（新建、从未保存）：菜单项**置灰**。没有磁盘上那一份，比不了，也不该让人点进去看一个空栏。
- **有当前文件但不脏**：能进，两栏一模一样，计数条写「没有改动」。这比置灰好——「我确实没改过」和「这个功能坏了」得能分辨。

## Consequences

- 菜单的对钩是互斥的，而 macOS 的菜单是应用级的；要让每个窗口显示自己的对钩，必须给每个窗口挂自己的菜单（`window.set_menu`）。这是这条决定的实现成本，不是它的附带损害——没有对钩，「我现在在哪个视图」就只能靠猜。
- 三个双页视图共用一套外壳：并排两栏、段段对齐、Esc、计数条。新增第四个对照（比如对比两个不同文件）时不需要再做一次决定，填内容即可。
