## What to build

界面从脚手架的样子变成 1c 定稿的样子：一条 34px 的标题栏，没有工具栏，窗口去掉系统边框。

## Acceptance criteria

- [ ] 标题栏高度 34px，其中只有三样东西：左侧交通灯、中央文件名、右侧字数
- [ ] 中央显示当前文件名；文档从未保存过时显示「未命名」
- [ ] 有未保存修改时文件名后出现 `*`，保存成功后立即消失
- [ ] 右侧显示当前字数，随输入更新
- [ ] 窗口使用自绘标题栏，不显示系统默认窗口边框
- [ ] 界面上没有工具栏——四个文件操作全部只走快捷键
- [ ] 标题栏的呈现与 `docs/design/project/Milktown 原型.dc.html` 一致

## Blocked by
