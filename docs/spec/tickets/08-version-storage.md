## What to build

保存时自动留存版本，历史真的在磁盘上攒起来。此时还没有界面能看到它们——这一票交付的是「历史确实存在且正确」。

## Acceptance criteria

- [ ] 版本存放在目标文件所在目录下的隐藏目录中（ADR 0005）
- [ ] 布局满足：可从单个文件路径定位到它的全部版本、可从条目还原出留存时刻、人工检视时可读
- [ ] 版本存储完整内容而非增量（ADR 0004）
- [ ] ⌘S 时留存一个版本
- [ ] 距上一个版本不足 **5 分钟**时覆盖它而非新增
- [ ] 打开文件与关闭文件两个时刻**无条件新增**一个版本，不受 5 分钟窗口约束
- [ ] 打开文件时在内存中计算规范化文本作为差异基线，**不产生任何磁盘写入**（ADR 0006）
- [ ] 历史按时间倒序返回
- [ ] 历史目录不存在时，列出历史返回空而不是报错
- [ ] 历史目录中存在无法识别的条目时跳过该条目，其余版本正常返回
- [ ] 磁盘写入失败时抛出错误，不被静默吞掉
- [ ] 同一目录下两个不同文件的历史互不干扰
- [ ] 应用不修改用户的 git 配置
- [ ] 历史模块注入**时钟**与**文件系统**两个端口；测试用可控时钟与内存文件系统，不触碰真实磁盘、不依赖真实时间流逝
- [ ] 留存版本不使 ⌘S 变慢到有感
