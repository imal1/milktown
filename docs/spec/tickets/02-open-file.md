## What to build

用户能通过系统原生的文件对话框打开电脑里真实存在的 `.md` 文件，内容以渲染后的样子出现在编辑器里，文件路径被应用记住。

## Acceptance criteria

- [ ] 安装 `@tauri-apps/plugin-fs` 与 `@tauri-apps/plugin-dialog` 的 JS 绑定（Rust 侧插件与 capabilities 已就位，无需改动）
- [ ] 通过系统原生对话框选择文件，可见收藏夹与最近位置
- [ ] 选中的 `.md` 文件内容被读入并显示为渲染后的样子
- [ ] 应用状态中记录该文件的完整路径，而不只是文件名
- [ ] 打开另一个文件时销毁旧编辑器实例、以新内容创建新实例，撤销历史随之清空（ADR 0002）
- [ ] 打开不存在或无读取权限的文件时，给出说明文件路径问题的提示，应用不崩溃
- [ ] 文件模块通过注入的文件系统与对话框实现工作，可在测试中替换为内存实现
- [ ] 文件模块的测试覆盖：打开返回正确的路径与内容、读取失败被正确抛出
