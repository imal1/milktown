## What to build

用户能翻回三小时前，并看出到底改了什么：快捷键进入双页视图，窗口被完全接管，一侧是选中的历史版本、一侧是当前内容，差异以行级增删标出。

## Acceptance criteria

- [ ] 快捷键进入双页视图（系统菜单栏中的可见入口属于后续阶段，不在本票内）
- [ ] 进入后接管整个窗口
- [ ] 版本列表按时间倒序排列，每项显示留存时间
- [ ] 方向键在版本之间移动
- [ ] 选中一个版本后**立刻**显示它与当前内容的差异，不需要再点一次「比较」
- [ ] 差异以增行与删行的形式标出
- [ ] 两侧滚动联动
- [ ] 两个版本之间没有差异时明确告知
- [ ] Esc 退出，回到写作
- [ ] 文档从未保存过（没有路径）时进入双页视图，给出清楚的说明
- [ ] 双页视图**不含业务逻辑**：只渲染历史模块返回的版本列表与差异结果，并把用户意图发出去
- [ ] 1c 标题栏未新增任何常驻控件

## Blocked by

- 「版本存储与留存策略」
- 「行级差异」
