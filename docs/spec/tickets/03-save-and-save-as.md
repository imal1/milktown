## What to build

用户按 ⌘S 把修改写回原来那个文件；文档从未保存过时弹出系统保存对话框；⇧⌘S 另存为新文件。文件名旁的 `*` 如实反映是否有未保存的修改。

**这一票通过之后，milktown 才第一次能完成它的核心任务。**

## Acceptance criteria

- [ ] ⌘S 把当前内容写回已有路径
- [ ] 文档没有路径时，⌘S 弹出系统保存对话框让用户选位置与文件名
- [ ] ⇧⌘S 弹出保存对话框，另存为新文件，当前文件切换为新路径
- [ ] ⌘N 新建空白文档
- [ ] 脏标记由编辑器的文档变更事件置位，由一次成功的保存清零；**不通过比对内容判定**（ADR 0002）
- [ ] 保存时向编辑器索取当前 Markdown，**绝不从应用状态取**（ADR 0002）
- [ ] 当前文档有未保存修改时，新建或打开另一个文件会先弹出确认
- [ ] 保存失败（无写权限、磁盘满）时明确告知用户，且脏标记不清零
- [ ] 全局快捷键只注册一处。旧实现中编辑器与工具栏各注册一份 ⌘S 监听器互相竞争，不得重现
- [ ] 组件之间不通过查询 DOM 互相触发。旧实现中应用组件靠 CSS 类名查到按钮再模拟点击，此类跨组件穿刺一律禁止
- [ ] 文件模块的测试覆盖：保存写到正确路径、未保存过的文档触发另存为流程、写入失败被抛出
