SPEC2_REF

## What to build

在两段**已规范化**的文本之间计算行级差异，产出增行、删行、未变行的序列。

这一票没有界面，单独看不出效果，但它是可验证的：差异算法出问题时不必在双页视图的界面里排查。

## Acceptance criteria

- [ ] 输入两段已规范化的文本，输出增行 / 删行 / 未变行的序列
- [ ] 差异**从不**在未规范化的文本上计算——否则格式噪音会淹没内容变化
- [ ] 内容未变时，差异为空
- [ ] 只改一行时，差异只报告那一行
- [ ] 有测试覆盖上述行为
