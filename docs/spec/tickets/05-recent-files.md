## What to build

用户不走文件对话框就能在常写的几篇之间跳转：点标题栏中央的文件名弹出最近文件面板，空白新文档的屏幕上直接列出最近文件。

## Acceptance criteria

- [ ] 点击标题栏中央的文件名，从标题栏下方浮出最近文件面板
- [ ] ⌘O 直接唤出该面板
- [ ] 面板中每一项显示文件名、所在目录、最后打开时间
- [ ] 上下方向键移动选择，回车打开，Esc 关闭面板
- [ ] 打开一篇空白新文档时，屏幕上直接显示最近文件列表；开始打字后立即消失
- [ ] 最近文件列表持久化到浏览器本地存储，应用重启后仍在（ADR 记录：这是最不重要的数据，不值得为它引入存储层）
- [ ] 最近打开的排在最前；重复打开同一文件不产生重复项；列表长度有上限
- [ ] 打开失败的文件从列表中移除或被标出
- [ ] 本地存储不可用时不导致崩溃
- [ ] 最近文件模块通过注入的键值存储工作；测试覆盖排序、去重、长度上限、存储不可用
