触发那些等不来的状态
文件名按钮
热区撑满标题栏 34px、最小宽 96px，视觉只有 22px 的圆角块。悬停 #F0ECE2，键盘聚焦再加 1.5px #8A8378 内描边。▾ 不是独立按钮。
脏标记
5px 圆点 #8F7A4A，在文件名与 ▾ 之间。* 紧贴文件名会被读成文件名的一部分，圆点是标记不是字符。Tweaks 里可换回星号。
字数
口径写在数字后面（「字」），颜色从 #A39B8E 换到 #6E675C——11px 压在米色上要过 4.5:1。点开是口径面板，不是第二个工具栏。
光标行显源码
要有。标记 mono 0.86em #6E675C：更淡的灰在 15px 上读不出来，就只剩装饰。行首标记悬挂在纸外，段落不左右跳；行内标记占位，只推挤当前行。显隐是纯 CSS 切换，光标不会掉。
输入法
compositionstart 到 compositionend 之间冻结标记显隐、也不更新字数。候选框还开着的时候纸面不许动。
排版与原文并排
「视图」第三项，⌥⌘/。左边排好版的、右边原文，对齐单位是段不是行——一段一格，两边同高，所以标题、引用、表格都能一眼对上。右边带整份连续行号（段间空行也数），悬停整行两边一起上 #F4F1E8 并在原文侧亮 2px 边标。点任意一段就回写作、光标落在那一段末尾；并排本身只读，Esc 退出。
磁盘与当前对照
版本对照，不是另一个页面：入口同在「视图」菜单（⇧⌘/，与 ⌘/、⌥⌘/ 三项互斥打勾）。左边磁盘上的那一份，右边当前；一个滚动容器里两列，天然联动。改动行 #F6E0DC / #E4EFDC、行内再深一档，空位 #FAF8F3，行号 #6E675C。↑↓ 在改动之间跳，Esc 回写作。只读——真正要改的那份在右边，退出就接着写。
内容控件统一皮
纸底 #FDFCF9 / 1px #E2DCCE / 6px 圆角 / 0 6px 20px -8px rgba(40,34,26,.28)，文字按钮不用图标，距目标 8px。链接、代码块语言、表格把手、图片、公式五处同一套。
