定稿参数
字体　IBM Plex Mono 15px / 1.8。比正文 18px 小一档、比代码块 13.5px 大一档，落在两者之间，读起来仍是「文章」不是「配置文件」。

过渡　纸张轻微上移淡入：新视图 translateY 6px → 0 / opacity 0 → 1，140ms ease-out；旧视图 70ms 淡出。标题栏和徽章不参与动画。

# 写作工具的一点想法
工具栏上的每个按钮都在偷高度。四个操作都有
快捷键，那条横栏留在屏幕上的唯一理由，
是让我确认文件还在。
> 去掉横栏之后，纸就是全部。那条横栏
> 只在你需要它时出现。
定稿参数
位置　纸张上方 22px 处的浮卡，左右与纸对齐（535px）。不通栏，不吸顶——通栏会让它看起来像工具栏，而这个应用不要工具栏。
字段　两行，标签在左（等宽 10px），输入是发丝下划线不是输入框。查找行获得焦点时下划线转深（#E2DCCE）。
计数　3 / 12，紧跟查找字段右侧；无匹配时显示 0 / 0 并把计数与下划线一起转灰，不弹任何提示。
高亮　全部匹配 #F0ECE2（沿用 --highlight），当前项 #D8E0D0（新增 --highlight-active，苔绿，同一明度层但换色相，扫一眼就能分出哪个是当前）。
进入　写作视图按 ⌘F：先走 2a 那套上移淡入切到源码模式，落定后查找条再淡入（错开 60ms），不要两件事同时动。
2c 拖拽文件悬停态 整页覆盖一层半透明纸色，正文退到后面。脏文档时多一行小字预告松手之后会先问保存。

你打开它之后，2026-09.md 在磁盘上被别的程序改过了。

磁盘上那份改于 14:02，你手上这份基于 11:20。覆盖会丢掉那边的改动。

另存为… ⏎ 覆盖 ⌘D 放弃保存 Esc
定稿参数
键位　⏎ = 另存为…（默认项，谁都不损失）；⌘D = 覆盖（沿用「破坏性走 ⌘D」的既有肌肉记忆）；Esc = 放弃保存，回编辑器，文档仍是脏的。
问句　主句点明因果顺序：「你打开它之后 …… 被别的程序改过了」。副句给两个时间戳，这是用户判断该覆盖还是该另存的唯一依据——只说「文件已被修改」等于让人猜。
壳　与现有 ConfirmLayer 完全一致，只把宽度 340 → 380px 容下两行问句，多一段 13px --muted 副句。按钮顺序照旧：主项在最左。
另存为之后　新路径成为当前文件，标题栏改名，磁盘上那份原封不动。不再追问。
2f 重复打开同一文件
静默聚焦，什么都不说。
窗口跳到眼前本身就是反馈，再加一条 toast 是在解释用户已经看见的事。唯一的例外要处理：那个窗口如果被最小化了，聚焦不会有可见变化——这种情况下取消最小化并轻微抖动一下窗口（macOS 的 requestUserAttention），仍然不出 toast。
如果那个已开着的窗口是脏的，也不做任何提示——用户看到标题栏上的 * 就知道。
顺带钉死
多窗口下「最近文件」是全局共享一份的：在 A 窗口打开的文件，B 窗口的 ⌘O 面板里也看得到，并且带一个极淡的 开着 标记（--muted 10px，右对齐在时间前面），点它＝聚焦那个窗口而不是新开。
2g 草稿恢复 内容直接装进编辑器，配一条停 6 秒的 toast。文档进来就是脏的，标题栏带 *。

定稿参数
时长　6 秒（「已保存」仍是 1.8 秒）。这条错过就不知道手上这份是恢复来的，值得占更久；但仍自动消失，不给关闭按钮。
文案　「已恢复上次未保存的草稿 · ⌘S 存成文件」。后半句是这条 toast 存在的理由：草稿仍未落盘，用户得知道下一步按什么。
互斥　有草稿＝编辑器里有内容＝空状态（最近文件列表）不出现。双击文件启动时文件优先，草稿留着不动，也不出 toast——留到下次真正空手启动时再说。
样式　沿用现有 .toast，不加图标不换色。
